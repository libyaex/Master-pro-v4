# Master-pro-v4 — Zero-Cost Multi-Exchange Trading Intelligence

منصة ذكاء سوق متعددة المنصات، **عربية أولاً** (RTL، داكنة)، بلا أي تكلفة إلزامية:

- **صفر** مفاتيح API مدفوعة، **صفر** اشتراكات بيانات، **صفر** استدعاءات ذكاء اصطناعي خارجية.
- الذكاء محلي بالكامل: مؤشرات، إحصاء، سيولة، كشف النظام (regime)، تقييم حتمي.
- بيانات عامة رسمية فقط من: Binance (Spot/Futures)، Bybit، MEXC، OKX، وCoinGecko كإثراء اختياري.
- أربع فئات أدوات **لا تُخلط أبداً**: كريبتو، ذهب مُرمَّز (PAXG/XAUT)، مشتقات ذهب مدرجة، XAUUSD الفوري (يُعرض "غير متوفر" إن لم يوجد مصدر مجاني موثوق).
- الوحدات المتقدمة M1–M6: ماسح تحكيم عبر المنصات، ذكاء الحيتان، كشف الإدراجات الجديدة والاختراقات، محرك إشارات قابل للشرح، تقييم استراتيجيات تكيفي، وترتيب الفرص.

> لا يوجد أي ادعاء بضمان ربح في أي مكان — منصة معلوماتية/تعليمية تحليلية.

## Quickstart (أمر واحد)

```bash
cp .env.example .env      # لا يحتوي أي مفاتيح
python -m pip install -r requirements.txt
python -m app.main        # يعمل بدون أي مفاتيح — بيانات عامة فقط
```

افتح `http://127.0.0.1:8000` — الواجهة PWA عربية RTL (اختيار PWA لأنها أخف وأسرع نشراً من Flutter بلا toolchain).

## Structure

```
app/                    # محرك المنصة (asyncio + FastAPI + SQLite WAL)
  connectors/           # موصلات REST/WebSocket عامة + محدد معدل token-bucket
  engine/               # بيانات السوق الموحدة، مؤشرات، كشف النظام
  strategies/           # إضافات: تحليل(context) -> Signal | None
  modules/m1..m6/       # الوحدات المتقدمة المستقلة (لكل وحدة config ومفتاح تشغيل)
  execution/            # طابور متين، آلة حالات الأوامر، paper/testnet/live
  risk/                 # بوابة صلبة قبل كل أمر + قاطع دائرة + kill switch
  backtest/             # backtester حدثي محلي + walk-forward + Monte Carlo
  web/                  # واجهة PWA عربية (RTL، داكنة)
tests/                  # شواهد موصلات، إعادة بناء دفتر، مؤشرات، بوابة المخاطر
ASSUMPTIONS.md          # كل افتراض ونقطة غير موثقة ومحدودية كل مصدر
COST_AUDIT.md           # تدقيق تكلفة/تبعيات لكل مكوّن ومصدر بيانات
```

## Modes

1. تحليل بيانات مسجلة (offline)
2. تداول ورقي (paper) — تنفيذ محاكى بعمولات وانزلاق من الدفتر الحقيقي
3. Testnet حيث توفره المنصة
4. تداول حقيقي (اختياري، مقفل حتى إتمام قائمة تحقق)

## Non-negotiables

- لا بيانات عشوائية أو افتراضية خارج اختبارات `tests/fixtures` (موسومة).
- مصدر متوقف/مقيّد = "غير متوفر" بسبب + آخر طابع زمني صالح، وليس تقديراً صامتاً.
- أمر غير مُنفَّذ ليس تداولاً؛ الفارق النظري ليس ربحاً محققاً.
- أسرار عبر متغيرات بيئة فقط، AES-256-GCM، لا تُسجل أبداً.
